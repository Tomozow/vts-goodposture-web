# 姿勢チェッカー

VTube Studio の顔の向きと位置から姿勢スコアを計算し、カスタムパラメータ `PostureScore`（0〜100）へ書き込みます。配信画面用のチェッカーは GitHub Pages の同じ URL を OBS ブラウザソースに置きます。

Python 版の姿勢モニターとは同時に起動しないでください。同時に書くと VTube Studio が注入を拒否します。Web 版でトークンを取り直すと、Python 版 `config.json` のトークンは無効になります。

## Chrome で開くページ

1. VTube Studio で API を有効にする（既定ポート 8001）。
2. https://tomozow.github.io/vts-goodposture-web/ を Chrome で開く。
3. 「接続」を押す。初回は VTube Studio にプラグイン許可が出ます。
4. 「監視開始」を押す。配信中はこのウィンドウを最小化せず、表示したままにします。タブが背面に回ると、約 1 秒でスコアは 100 に戻ります。
5. 良い姿勢のときに「今の姿勢を基準にする」を押す。監視中は一度止めてから押してください。

接続先は `ws://127.0.0.1` です。`localhost` は使いません。ポートを変えた場合は、オーバーレイ URL も差し替えます。

Chrome がローカルネットワークアクセスを拒否すると接続できません。許可したあと、ページが再接続します。

認証トークンはこのブラウザの localStorage にだけ保存します。URL やリポジトリには入りません。`github.io` は同じアカウントの別 Pages とオリジンを共有するため、信頼できないページを同じアカウントの Pages に置かないでください。

## OBS ブラウザソース

操作ページの「今の設定でオーバーレイ URL をコピー」で出る URL を、ブラウザソースに貼ります。この URL はスコアと警告音だけです。設定やキャリブレーションは出ません。

例:

`?overlay=1&alert=1&threshold=70&duration=3&cooldown=10&volume=0.5&port=8001`

- 背景は透過です。クロマキーは不要です。
- 初回だけ、オーバーレイ用プラグインの許可が VTube Studio に出ます。
- 警告の閾値や音量を変えたら、操作ページで URL をコピーし直し、ブラウザソースの URL を差し替えます。
- 「表示されていないときにソースをシャットダウン」はオフにします。シーンから外れるとページが止まり、音も鳴りません。
- 警告音を配信に乗せるには、ブラウザソースの「OBS で音声を制御」をオンにします。
- 操作ページを閉じると、約 1 秒後に表示は 100 に戻り、警告も止まります。
- `PostureScore` がまだ無いときは「未接続」と出ます。

マネージャーの OBS 用 URL 一覧には、この Pages の URL は出ません。
